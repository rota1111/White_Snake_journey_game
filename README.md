# White_Snake_journey_game
## 项目结构
```
.
├── README.md
├── errors.txt                  错误日志
├── fun_little_game             小游戏源码目录
├── game
│   ├── SourceHanSansLite.ttf
│   ├── audio/                  音频文件
│   ├── cache/                  缓存文件
│   ├── gui/                    GUI使用的图片文件
│   ├── gui.rpy                 所有GUI相关变量定义
│   ├── images/                  图片文件
│   ├── options.rpy             配置和构筑相关变量
│   ├── saves
│   ├── screens.rpy             界面定义
│   ├── script.rpy              剧情脚本
│   └── tl/                     翻译文件
├── log.txt                     日志记录
├── project.json
└── 《白蛇之旅》——小游戏设计策划案.docx
```
