# White_Snake_journey_game  
基于renpy构建的galgame小游戏，剧情文档改编自《白蛇缘起》。
## 项目结构
```
.
├── README.md
├── errors.txt                  // 错误日志
├── copy.md                     // 剧情文案
├── game
│   ├── SourceHanSansLite.ttf   // 字体
│   ├── audio/                  // 音频文件
│   ├── cache/                  // 缓存文件
│   ├── gui/                    // GUI使用的图片文件
│   ├── gui.rpy                 // 所有GUI相关变量定义
│   ├── images/                 // 图片文件
│   ├── options.rpy             // 配置和构筑相关变量
│   ├── saves                   // 游戏存档
│   ├── screens.rpy             // 界面定义
│   ├── script.rpy              // 开始章节剧情脚本
│   ├── xu_or_bai_*_section.rpy // 不同章节剧情脚本
│   └── tl/                     // 翻译文件
├── log.txt                     // 日志记录
└── project.json 
```
## 游玩指南 
点击右侧realse下载发行版本,解压点击exe版本游玩  

除了正常的galgame流程外，还加入两个小游戏，点灯与打地鼠。
