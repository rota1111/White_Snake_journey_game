# White_Snake_journey_game
test/ 为测试  
test-bin/ 为test生成的发行版,zip里有exe  
white snake journey/ 为游戏正式目录
在game/目录下结构为:
```
.
├── SourceHanSansLite.ttf
├── audio/                  音频文件
├── cache/                  缓存文件
├── gui/                    GUI使用的图片文件
├── gui.rpy                 所有GUI相关变量定义
├── images/                 图片文件
├── options.rpy             配置和构筑相关变量
├── saves/                  
├── screens.rpy             界面定义
├── script.rpy              剧情脚本
└── tl/     翻译文件
```
